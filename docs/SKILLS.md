# Claude skills for this project

Using every skill at once adds noise, so use the one that fits the job. Names are as listed in Claude Code.

| Task | Skill | Used so far |
| --- | --- | --- |
| Any Oddjob UI change | `oddjob-design` (in this repo) | Written for this project |
| Marketing pages, art direction, checks | `taste-skill:taste-skill` | Direction, lint, inspector, critique |
| App screens, accessibility, UX rules | `ui-ux-pro-max` | Not yet. Use for the signed-in app |
| Component styling | `anthropic-skills:ui-styling` | Not yet |
| Reviewing against web standards | `anthropic-skills:web-design-guidelines` | Not yet. Run before launch |
| Hero and scroll motion | `gsap-scrolltrigger`, `gsap-react`, `gsap-performance` | Followed their patterns |
| Claude job cards | `claude-api` | Used for `/api/interpret` |
| Security pass | `security-review` | Not yet. Run before each release |
| Code review | `code-review` | Not yet |
| Logo and brand board | `taste-skill:brandkit` | Not yet. Needs final name checks first |
| Launch film or ads | `remotion:*` | Not yet. Optional |
| Investor or partner deck | `pptx-deck:create-deck` | Not yet. Optional |
| Market or legal research | `anthropic-skills:deep-research` | Not yet. Use once the country is chosen |

## Project skill

`.claude/skills/oddjob-design/SKILL.md` holds the design rules, so they load whenever Claude works on the interface.
